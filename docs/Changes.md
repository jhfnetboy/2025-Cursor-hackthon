## Version 0.1.5 (2025-12-06)

### 安全性增强
- 实现安全的后端API架构，保护ElevenLabs API密钥
- 将API密钥从前端移至后端服务器，避免暴露给客户端
- 添加CORS配置，确保安全的跨域通信
- 实现环境变量管理，使用ELEVENLABS_API_KEY

### 架构重构
- 创建独立的Express后端服务 (端口3000)
- 前端 (端口5173) 通过HTTP请求调用后端API
- 后端处理所有ElevenLabs API交互
- 前端专注于UI和用户体验

### 后端服务特性
- Node.js + Express服务器架构
- 安全的API密钥存储和管理
- 健康检查端点 (/health)
- 音乐生成API端点 (/api/generate-music)
- 错误处理和日志记录
- Base64音频数据传输

### 开发环境优化
- 更新package.json脚本，支持前后端同时开发
- 添加后端开发命令 (pnpm dev:backend)
- 配置环境变量加载 (.env文件)
- 完善开发工作流程文档

### 安全性改进
- API密钥完全隔离在后端
- 前端无需访问敏感凭据
- HTTPS-ready架构设计
- 输入验证和错误处理

### 部署说明更新
