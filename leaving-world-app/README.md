# 🌹 Leaving the World with Love and Happiness

A compassionate digital time capsule application for people who wish to leave behind messages of love, cherished memories, and heartfelt voice recordings for their loved ones.

## ✨ Features

- **💌 Messages of Love** - Write heartfelt letters and messages
- **📸 Precious Memories** - Upload and organize photos with captions
- **🎤 Voice from Heart** - Record voice messages with transcription
- **📅 Future Delivery** - Schedule content delivery to loved ones
- **🎨 Beautiful Interface** - Warm, compassionate design with animations
- **📱 Responsive Design** - Works on all devices

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Open http://localhost:5174
```

## 🎯 Purpose

This application was created with deep compassion for individuals facing terminal illness who wish to:

- Leave behind messages of love and encouragement
- Share precious memories and life lessons
- Record voice messages that capture their personality
- Schedule future deliveries for important life moments
- Create a lasting digital legacy of love

## 🛠️ Technology Stack

- **Frontend**: React 18 + TypeScript
- **Routing**: React Router v6
- **Styling**: CSS-in-JS with responsive design
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite 6
- **Package Manager**: pnpm

## 🌟 Features in Detail

### Messages of Love
- Rich text editor with placeholder inspiration
- Character counting and validation
- Save drafts and edit existing messages
- Categorize by recipient

### Precious Memories
- Drag & drop photo upload
- Add titles and descriptions
- Organize into collections
- Preview and edit metadata

### Voice from Heart
- Browser-based audio recording
- Real-time duration tracking
- Automatic transcription (simulated)
- Playback and download options

### Future Delivery
- Calendar-based scheduling
- Multiple delivery methods (future: email, SMS, social media)
- Status tracking and notifications
- Flexible timing options
